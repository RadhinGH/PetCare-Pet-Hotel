PetCare - Sistem Informasi Pet Care & Pet Hotel (Kelompok 06)
==============================================================

Syarat : Java (JRE/JDK) versi 17 atau lebih baru.

Cara menjalankan:
  1. Pastikan PetCare.jar dan folder lib/ berada di folder yang sama.
  2. Buka terminal / CMD di folder ini, lalu jalankan:
       java -jar PetCare.jar
     (atau klik dua kali PetCare.jar)

Catatan:
  - Saat pertama dijalankan, file database pethotel.db dibuat otomatis
    di folder ini lengkap dengan data awal.
  - Library pendukung: lib/sqlite-jdbc-3.54.1.0.jar (driver SQLite).
